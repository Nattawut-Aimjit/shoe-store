

(ร้านขายรองเท้าออนไลน์)



เว็บร้านขายรองเท้า พัฒนาด้วย PHP และ MySQL



\*หมายเหตุ: ข้อมูลทั้งหมดเป็นข้อมูลจำลองเพื่อการทดสอบเท่านั้น\*



\## ฟีเจอร์

\- สมัครสมาชิก / เข้าสู่ระบบ / ลืมรหัสผ่าน

\- ดูรายการสินค้า รายละเอียดสินค้า ตะกร้า และชำระเงิน

\- ดูประวัติคำสั่งซื้อ

\- หลังบ้านผู้ดูแล: จัดการสินค้า ลูกค้า คำสั่งซื้อ และรายงาน



\## วิธีติดตั้ง

1\. ติดตั้ง XAMPP แล้วคัดลอกโฟลเดอร์นี้ไปไว้ใน htdocs

2\. สร้างฐานข้อมูลใน phpMyAdmin

###### 3\. สร้างไฟล์ db.php สำหรับเชื่อมต่อฐานข้อมูลของคุณเอง
